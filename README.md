# Mdomalds

Static restaurant order queue demo with a customer ordering page and an admin queue/menu page.

## Files

- `index.html` - customer order page.
- `admin.html` - menu and order management page.
- `style.css` - responsive dark UI.
- `app.js` - customer menu, cart, and queue behavior.
- `admin.js` - admin menu and order management behavior.

## Preview

Open `index.html` directly in a browser, or serve the folder:

```powershell
py -m http.server 8000
```

Then open `http://localhost:8000`.
